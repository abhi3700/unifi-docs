## What is UniFi CLI?

The **UniFi CLI** allows developers to interact with UniFi directly from the terminal — enabling payments, wallet management, and automation workflows.

## Requirements

To use the CLI effectively, you need the following:

<Columns cols={2}>
  <Card title="Account Setup" icon="key">

The CLI supports two account types:

- an **AWS KMS-backed wallet**;
- an **email-based UniFi account**.

The CLI cannot connect directly to Web3 wallets such as MetaMask. Browser-wallet connections are
available through the UniFi web app instead.

<Note>
For automation and unattended workflows, use **AWS KMS** so signing keys remain protected by the
KMS security boundary.
</Note>

> Support for additional managed-key providers is planned for a future release.

  </Card>

  <Card title="UniFi Infra" icon="credit-card">

    The CLI works on top of **UniFi’s stablecoin payment infrastructure**, which powers:

    - Gasless transactions
    - Fast and low-cost transfers
    - Multi-chain payments
    - Scheduled payments
    - Bulk payments (e.g., payroll disbursals)
    - High-volume automated payouts
