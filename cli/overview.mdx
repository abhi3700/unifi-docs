The UniFi CLI is an early developer interface for wallet connection, testnet funding, balances, deposits, configuration, and API-key management.

## Current command surface

- connect or disconnect an AWS KMS-backed wallet
- inspect or update CLI configuration
- request Sepolia faucet tokens
- display the deposit address
- inspect wallet balances
- create, view, and revoke API keys

<Info>
Payment submission is not currently exposed as a CLI command. Use the web app or API for payment creation.
</Info>

The CLI stores local connection configuration but delegates wallet signing to AWS KMS through the AWS CLI. Protect both the local configuration and the AWS account.
