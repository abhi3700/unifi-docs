## 0.1.0

The current repository package is version `0.1.0`.

### Available

- AWS KMS wallet connection and disconnection
- configurable API base URL and wallet alias
- Sepolia faucet commands for USDT, USDC, and DAI
- deposit address and balance views
- API-key creation, listing, and revocation
