Protected operations accept a `UNIFI_API_KEY`:

```http
Authorization: Bearer <credential>
```

**Q. How to obtain it?** \
**A.** Create a named key from the UniFi [web app](https://payunifi.com/app/api).

## API keys for server integrations

Create a named API key in the UniFi web app and store it in a server-side secret manager.

This is a sample curl API request for getting USDT balance on Ethereum.

```bash
curl --request GET \
  --url https://api.payunifi.com/wallet/onchain/balance/USER_ID/Ethereum/USDT \
  --header "Authorization: Bearer $UNIFI_API_KEY"
```

The credential must be authorized for the `user_id` in user-scoped routes. Never ship the key in
browser JavaScript, a public repository, a mobile binary, logs, or analytics events.
