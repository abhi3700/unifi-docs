The UniFi API gives developers a simple way to integrate stablecoin payments without dealing with the complexity
of UniFi Infra directly.

It abstracts the underlying payment infrastructure into a clean set of API endpoints,
so you can build checkout flows, manage wallets, and process payments through a straightforward developer interface.

## Base URL

```text
https://api.payunifi.com
```

All requests use HTTPS and JSON unless an endpoint states otherwise.

## Authentication

Almost all operations require a bearer credential:

```http
Authorization: Bearer <credential>
```

Use a server-side API key for backend integrations.

<Warning>
    Never expose an API key in browser code, a mobile application, a public
    repository, logs, or analytics events.
</Warning>

## Response envelope

Successful data responses use a consistent envelope:

```json
{
    "status": "200 OK",
    "data": {}
}
```

Operations that do not return a resource use `message` instead of `data`. Error responses are
currently plain text, so application logic should branch on the HTTP status rather than parsing the
message.
