This quickstart follows the web app that runs at `/app`. You can explore the home screen and public
API plans without signing in; wallet balances, deposits, payments, history, and API keys require an
authenticated session.

## 2. Start from a quick action

The home page offers four entry points:

- **Pay** — select an asset and network, enter a recipient and amount, then review and authorize.
- **Scan** — read a UniFi payment QR and open its payment flow.
- **Receive** — create a FliQR link and QR for a requested amount.
- **Deposit** — display the wallet address and token contract information for the selected pair.

Selecting a network or stablecoin on the home screen opens the same pair picker used by the
payment flow.

## 3. Select the asset and network

The current web app exposes USDT, USDC, and DAI. The exact network list depends on the environment
and account type.

<Warning>
Always match both the stablecoin and the network. The Deposit screen shows the token contract and a
warning because sending another asset or using another network can permanently lose funds.
</Warning>

## 4. Review and authorize

For an email account, a protected payment is completed with authenticator OTP. For a connected
wallet, UniFi checks balance and Permit2 allowance, asks for token approval when required, and then
asks the wallet to sign the payment details. The payment signature expires after 15 minutes.

<Tip>
"Gasless" applies to the supported payment execution. A first-time ERC-20 approval is an onchain
transaction and normally needs the network's native token.
</Tip>

## 5. Track the receipt

Use **Activity** to open History, search by asset, network, amount, address, or receipt ID, and open
the receipt. Treat `Finalized` as the completed success state; `Submitted` and `Confirmed` still
represent work in progress.
