## ⚡ Start with UniFi

UniFi is a **global stablecoin payment platform** that enables:

- 🚫⛽ Gasless transactions
- 🌍 Multi-chain payments
- ⚡ Instant & low-cost transfers
- 🔐 Privacy-first design
- 💸 Bulk & scheduled payments

<Tip>Built for real-world payments — from individuals to enterprises.</Tip>

### Create API access

<Steps>
  <Step title="Open the Keys view">
    Sign in to the UniFi web app, open **API**, and select **New API Key**.
  </Step>
  <Step title="Create and secure the key">
    Give the key a unique integration name, create it, and copy it into a server-side secret
    manager.
  </Step>
  <Step title="Monitor or revoke access">
    Review credits from **Quota** and delete keys as soon as an integration no longer needs them.
  </Step>
</Steps>

<Card title="Follow the API key walkthrough" icon="key" href="/api-reference/authentication">
  See every step in the web app, then add the bearer credential to your server integration.
</Card>
