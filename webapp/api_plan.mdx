title: "API plans"
description: "Understand API access, credits, and plan metadata."
icon: "chart-column"
---

The API plan view reports the current plan, duration, remaining credits, image-processing credits, and expiry time associated with the account.

Before changing a plan:

1. Check the current expiry and remaining credits.
2. Review the purchase asset, network, amount, and fee estimate.
3. Confirm which environment the plan applies to.
4. Save the resulting receipt.

Plan names, prices, and limits can change. Treat the values displayed in the app at purchase time as authoritative.
