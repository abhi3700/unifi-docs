Deposit is a protected route. It resolves the current wallet address, then presents a stablecoin
and network pair with the information needed to transfer that exact token.

## Choose the pair

The pair sheet lists **Assets** and **Networks**. A selection opens the typed route
`/app/wallet/deposit/:chain/:coin`, so the address screen always knows both values.

## What the address screen shows

- the selected stablecoin and network;
- a QR code for the wallet address;
- a copyable wallet address;
- the ERC-20 token contract for the selected supported network;
- a chain-explorer link for supported public networks;
- three steps: copy the address, send the selected ERC-20, and wait for confirmation.

<Warning>
Send only the displayed stablecoin on the displayed network. The screen deliberately repeats this
warning because a different asset or network can permanently lose funds.
</Warning>

## Copy and share

The copy action shares the wallet address as text. The Share action renders the deposit card as an
image and includes a link when Web Share is available; unsupported browsers fall back to the
available copy or download behavior.
