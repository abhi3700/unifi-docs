Home is the public entry point at `/app`. It introduces the payment wallet and keeps the most common
actions above the network and stablecoin selectors.

## Quick actions

| Action  | Opens                                                 |
| ------- | ----------------------------------------------------- |
| Pay     | Send stablecoin                                       |
| Scan    | Scan an address, then continue to the payment page.   |
| Receive | Create link to receive payment                        |
| Deposit | Select asset & network -> View deposit wallet address |

Protected actions require authentication. If you open one while signed out—such as a payment
link—UniFi asks you to sign in with email or connect a wallet, then returns you to the requested
page after authentication.

## Asset-Network selection

The **Networks** row starts from a network and asks for a stablecoin. The **Stablecoins** row starts
from an asset and asks for a network. Both paths end at the same typed route, so the following screen
receives an explicit `(coin, chain)` pair.

## Navigate the app

The persistent navigation keeps the primary destinations within reach:

- **Home** returns to the overview and quick actions.
- **Wallet** opens balances and funding tools.
- **Pay** starts the send or receive flow.
- **Activity** opens payment history.
- **More** groups additional wallet, payment, history, and API tools.

Select the UniFi logo from the expanded menu to return to Home. Expand **Wallet**, **Payment**, or
**API** to reveal their related destinations without crowding the primary navigation.
