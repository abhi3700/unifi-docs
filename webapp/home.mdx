The home page is the starting point for common actions:

- **Pay** to send a stablecoin to a wallet address or payment request.
- **Request** to create a shareable link or QR code.
- **Wallet** to view balances and deposit addresses.
- **History** to revisit receipts and payment state.
- **Developer** to create API credentials and inspect plan usage.

The selected asset control always represents a token-network pair. Look for both the stablecoin icon and the chain badge before continuing.
