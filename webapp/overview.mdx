receipts, history, and API access in one responsive Dioxus application.

## Main journeys

<Columns cols={2}>
  <Card title="Fund and inspect a wallet" icon="wallet" href="/webapp/deposit">
    Choose a stablecoin and network, copy the wallet address, verify the token contract, and then
    inspect balances by asset and network.
  </Card>
  <Card title="Send a payment" icon="send" href="/webapp/pay_send">
    Enter a recipient and amount, review fees, authorize the payment, and follow its receipt.
  </Card>
  <Card title="Request a payment" icon="link" href="/webapp/pay_request">
    Create a FliQR link and QR code for a specific stablecoin, network, recipient, and amount.
  </Card>
  <Card title="Track activity" icon="history" href="/webapp/pay_history">
    Filter or search payment history, open receipt details, and share a receipt.
  </Card>
</Columns>

## Account models

| Account | Authorization | Wallet behavior |
| --- | --- | --- |
| Email | Password plus authenticator OTP for protected actions | UniFi-managed custodial wallet |
| MetaMask | Wallet challenge for login; Permit2 approval and payment signature when required | Self-custodial EVM wallet |

The protected routes redirect to Auth when the user has no valid session. Public routes include the
home screen and the API-plan catalog.

## Supported choices in the current UI

- Stablecoins: USDT, USDC, and DAI.
- Networks: Ethereum, Polygon, and Sepolia.

<Note>
Network availability can vary by account and product configuration. Start from the choices shown
in the app so the payment and deposit flows remain on a supported pair.
</Note>

## Bottom navigation

The persistent product navigation provides **Home**, **Wallet**, **Pay**, **Activity**, and **More**.
The centered Pay action opens the payment workflow; the home-page quick actions open the same
underlying routes with the selected asset and network carried forward.
