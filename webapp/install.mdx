## Install UniFi

Open the [UniFi payment app](https://payunifi.com/app). If your browser shows an **install icon**
in the address bar, select it and confirm **Install**. You can also select the download icon next
to **Install UniFi** on the payment home, or select **Install UniFi** on the [UniFi homepage](https://payunifi.com/).

The installed app opens the payment home at `/app`. Payments and balance updates require an
internet connection.

## Install UniFi Docs

Open the [UniFi Docs homepage](/) and select the download icon next to **Docs** in the header.
Once installed, UniFi Docs opens in its own window.

## Install from your browser menu

If the browser does not show a prompt, first open the payment app or the Docs homepage, then follow the steps for your device.

| Device | Steps |
| --- | --- |
| iOS · Safari | On iPhone or iPad, tap **Share → Add to Home Screen**. Turn on **Open as Web App** if shown, then tap **Add**. |
| Android · Chrome or Brave | Open the menu and tap **Install app**. If you see **Add to Home screen** or **Install and create shortcut**, open it first. |
| Android · Firefox | Open the menu, tap **Install**, and add the app to your home screen. |
| Android · Edge | Open the menu and choose **Add to phone → Install**. |
| Android · Samsung Internet or Vivaldi | Open the menu and choose **Add page to → Home screen**. Tap **Install** if shown. |
| Android · Opera | Open the menu next to the address bar and choose **Add to → Home screen**. |
| Mac · Safari | On macOS 14 or later, choose **File → Add to Dock**, then click **Add**. |
| Mac or desktop · Chrome | Open the menu and choose **Cast, save, and share → Install page as app**. |
| Mac or desktop · Brave | Open the menu and choose **Save and Share → Install page as app**. |
| Mac or desktop · Edge | Open the menu and choose **More tools → Apps → Install this site as an app**. |
| Mac or desktop · Vivaldi | Right-click the tab and choose **Progressive Web Apps → Install**. |
| Windows · Firefox | Select the web apps icon in the address bar. |
