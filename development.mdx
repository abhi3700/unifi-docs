## API environments

| Environment | Base URL | Purpose |
| --- | --- | --- |
| Hosted | `https://unifi-api-4a5e.onrender.com` | Current public service |
| Local | `http://127.0.0.1:3333` | Local backend development |

Keep the base URL configurable in your integration. Do not hard-code a test or local host into production builds.

## Canonical request values

### Chains

Use the serialized chain names below:

- `Ethereum`
- `Polygon`
- `Sepolia` for testnet flows
- `Anvil` for local development

### Stablecoins

- `USDT`
- `USDC`
- `DAI`

Support depends on the selected environment and deployed contracts. A value being accepted by the type system does not guarantee liquidity or availability in every deployment.

### Receipt states

| Status | Meaning |
| --- | --- |
| `Processing` | UniFi accepted the payment for execution. |
| `Confirmed` | The transaction was included in a block and has a transaction hash. |
| `Finalized` | The transaction was observed at finalized chain status. |
| `Failed` | Validation or execution failed. |
| `Reorged` | The transaction is no longer on the canonical chain; retry may be required. |

## Local health check

```bash
curl http://127.0.0.1:3333/healthz
```

A healthy service returns JSON with `status`, `data`, and `server_uptime`.
